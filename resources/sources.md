# Sources & Attribution

This course is an original work that synthesizes, adapts, and credits nine primary
sources. Where material is adapted (rather than merely cited), the page carries an
attribution note pointing back here. The repository is licensed [MIT](../LICENSE);
adapted MIT material retains its original attribution below.

## The nine primary sources

### 1. Panaversity — *Loop Engineering: A Crash Course*

- **Provenance:** agentfactory.panaversity.org
- **Role in this course:** the backbone — its 15 concepts, 6-part structure,
  8 projects, and Routines appendix shape our 14-step roadmap, `docs/projects/`
  labs, and `docs/appendix/`.

### 2. Panaversity — *Agentic Coding Crash Course*

- **Provenance:** companion chapter, agentfactory.panaversity.org
- **Role:** the primitives loops are built from — plan mode, permissions, context,
  rules files, skills, hooks, subagents, MCP. Basis for
  `docs/prerequisites/agentic-coding-primer.md` and `docs/00-foundations/primitives.md`.

### 3. Panaversity — *Spec-Driven Development*

- **Provenance:** companion chapter, agentfactory.panaversity.org
- **Role:** why stopping conditions work — vibe-vs-spec, the constitution, the
  4-phase method. Basis for `docs/prerequisites/spec-driven-primer.md`.

### 4. Panaversity — *Scheduled Tasks: The Loop Skill & Cron Tools*

- **Provenance:** companion chapter, agentfactory.panaversity.org
- **Role:** heartbeat depth — `/loop`, interval syntax, `Cron*` tools, limits,
  jitter, troubleshooting. Feeds Part 2 (Steps 04–07).

### 5. Addy Osmani — *Loop Engineering*

- **Provenance:** addyosmani.com
- **Role:** the named pattern; the five parts + memory framing; the "stay the
  engineer" principle that anchors Part 6.

### 6. Sydney Runkle (LangChain) — *The Art of Loop Engineering*

- **Provenance:** LangChain blog
- **Role:** the 4-loop stack (agent → verification → event → hill-climbing) and the
  term "loopcraft". Feeds `docs/advanced/loopcraft-stacking-loops.md`.

### 7. cobusgreyling / loop-engineering

- **Provenance:** GitHub, **MIT license**
- **Role:** starter kits, the 7 patterns, scaffolding files, the `loop-*` CLI tools,
  the Loop Ready score, per-tool examples, and stories. This is the only source we
  **adapt files from** (never wholesale); every adapted file carries an attribution
  header naming this repo and its MIT license.

### 8. Peter Steinberger & Boris Cherny — public statements

- **Provenance:** The New Stack, Business Insider, X
- **Role:** origin quotes that motivate the practice — the "why now" of Part 1.

### 9. Andrew Ng & Andrej Karpathy — public statements

- **Provenance:** X
- **Role:** Ng's three nested loops (the human's context advantage) and Karpathy on
  success criteria — feed Part 6 and `docs/part-6-human-control/the-three-nested-loops.md`.

## Attribution policy

1. **Cite, don't copy.** Original prose throughout; quotes are short, marked, and
   credited inline.
2. **Adapted MIT files** (source 7 only) keep an attribution header and are listed
   here when added.
3. **Mechanics change weekly.** Tool commands are framed as pointers to each tool's
   live documentation rather than authoritative references.
4. Corrections and attribution requests: open an issue with the `content-fix` template.
