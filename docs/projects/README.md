# Projects

> Eleven graded labs. Each one builds a working loop end to end, then breaks it on purpose so
> you learn what failure looks like before production teaches you.

Work them in order — each lab assumes the parts built in the one before it.

| # | Project | What you build |
|---|---|---|
| 01 | [A watch loop](01-a-watch-loop.md) | Your first heartbeat |
| 02 | [Make the tests pass, then stop](02-make-the-tests-pass-then-stop.md) | A real stopping condition |
| 03 | [The morning brief with a memory](03-the-morning-brief-with-a-memory.md) | A spine that survives restarts |
| 04 | [A fix loop with a real checker](04-a-fix-loop-with-a-real-checker.md) | Maker ≠ checker, enforced |
| 05 | [Codify the body](05-codify-the-body.md) | Explicit capability boundaries |
| 06 | [The doorbell loop](06-the-doorbell-loop.md) | Event-driven triggers |
| 07 | [Break it on purpose](07-break-it-on-purpose.md) | Failure modes, deliberately induced |
| 08 | [Your own daily loop (capstone)](08-your-own-daily-loop-capstone.md) | A loop you actually run |
| 09 | [Rehearse a routine for free](09-rehearse-a-routine-for-free.md) | Dry runs without burning tokens |
| 10 | [The secrets drill](10-the-secrets-drill.md) | Credentials a loop must never leak |
| 11 | [The two-routine gate](11-the-two-routine-gate.md) | Human control at scale |

Worked solutions live in [`solutions/`](solutions/README.md). Read yours only after you've shipped a
version that runs — the labs grade the loop you built, not the one you recognized.
