## What "Loop Ready" means

**Loop Ready is an auditable score, not a badge.** It certifies that you can design a loop that
declares all six parts — heartbeat, body, spine, stopping condition, checker, and human gate —
and that the loop you built is verified by something other than itself.

The per-part quizzes throughout the course are practice. These are the graded artifacts.
